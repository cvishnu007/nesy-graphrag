## ⚡ Contradiction Detection

Evidence: queries whose first five results include a pair that the human rater labelled a contradiction (2) or tension (1) in round 2 (`evaluation/human_review/contradiction_round2_sheet_labeled_cv.csv`; RESULTS §5b-2). The mode shows disagreements only between papers linked by a citation, so it needs topics where papers explicitly revisit each other.

| Query | Human-confirmed pair you should see |
|---|---|
| representation learning for Stack Overflow posts | **Contradiction:** Post2Vec reports 15–25% F1 gains; a follow-up finds it does not improve on the state of the art |
| low-dimensional embeddings of complex networks | **Contradiction:** low-dimensional embeddings "provably cannot capture" triangle-rich networks vs exact low-rank factorizations of real networks |
| LLM-based agents for software engineering | Tension: Agentless (a simple non-agent pipeline) beats agent systems vs SWE-agent and an agent survey (2 pairs) |
| benchmarking bias mitigation methods | Tension: mitigation methods are often ineffective (Fairea) vs Fairway mitigating bias without hurting accuracy |
| fairness and bias mitigation in machine learning models | Same Fairea vs Fairway tension |
| fairness in graph neural networks | Tension: simple re-balancing matches specialised fair GNNs |
| benchmarking heterogeneous graph neural networks | Tension: tuned GCN/GAT match heterogeneous GNNs vs Graph Transformer Networks claiming state of the art |
| self-training and confidence calibration in graph neural networks | Tension: high-confidence pseudo-labels can mislead vs calibrated confidence improves self-training |
| graph foundation models | Tension: GraphLand finds graph foundation models uncompetitive vs "graph foundation models are already here" |
| evaluation of multimodal large language models | Tension: MLLMs rely on shortcut learning vs a survey's view of human-like capability |
| out-of-core and multi-GPU training of graph neural networks | Tension: single-GPU out-of-core training beats multi-GPU systems (MariusGNN vs PaGraph) |

Pairs the verdict model marks 🔴 CONTRADICTION are its best guesses: 5 of the 9 it flagged were judged a contradiction or tension by the human. Many benchmark topics return no pairs at all. Broad terms usually return none.

## How these were measured

- Review: per-query NDCG@10 and P@10 recomputed from the frozen stratified rankings and judge labels.
- Contradiction, Hypothesis, Related Work: each query was run through the app's retrieval code with no language-model call. Contradiction pairs were matched against the human-labelled round-2 pairs. "graph neural networks for fraud detection" comes from an earlier run of the same code.
- Results come from this corpus. After the corpus expansion, these lists need re-measuring.
